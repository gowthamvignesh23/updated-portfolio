## 🚀 Key Highlights & Interactive Features

- **🌌 Celestial Canvas Particle Background**: Custom HTML5 Canvas rendering glowing orbital particles and constellation links with mouse proximity avoidance physics.
- **🔦 Cursor Spotlight Effect**: Ambient radial spotlight gradient tracking mouse movements inspired by award-winning developer portfolios.
- **🃏 3D Perspective Card Tilt & Glare**: Dynamic multi-axis tilt calculations reacting to cursor coordinates with realistic specular glare reflection.
- **💻 Embedded Linux & Python CLI Terminal**: Fully functional in-browser terminal emulator supporting commands like `help`, `about`, `skills`, `projects`, `exp`, `edu`, `theme <name>`, and `clear`.
- **🧪 Interactive Python Code Playground**: Run simulated production Python scripts demonstrating Machine Learning classification pipelines, IoT telemetry ingestion, and REST API endpoints.
- **🎨 Multi-Theme Color Engine**: Instant accent switching across 5 curated themes (*Violet Aurora*, *Cyber Cyan*, *Emerald Matrix*, *Solar Amber*, and *Neon Rose*).
- **📄 Printable Resume Modal**: One-click printable, PDF-ready curriculum vitae preview with formatted typography and print media query styling.
- **🔍 Deep-Dive Project Architecture Modals**: Detailed blueprints, technical challenges solved, stack badges, and GitHub code links.
- **🎉 Interactive Confetti**: Celebration bursts upon copying contact email or sending messages.

## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `yarn`

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/gowthamvignesh23/updated-portfolio.git
   cd updated-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
